## О проекте

SuperPinger Desktop переносит возможности мониторинга мобильного SuperPinger на Windows. Размещайте хосты на карте, следите за их доступностью, просматривайте графики пинга и получайте Telegram-уведомления о падениях и восстановлениях. Мониторинг продолжается, когда приложение свёрнуто в системный трей.

![Главный экран SuperPinger Desktop](docs/images/overview.png)

## Возможности

| Функция | Что можно делать |
|---|---|
| **Мониторинг хостов** | Проверять IPv4, IPv6 и DNS-имена автоматически или вручную. Настраивать размер данных ICMP, таймаут и порог неудач для каждого хоста. |
| **Интерактивная карта** | Выбрать место на OpenStreetMap и закрепить имя и адрес хоста. Зелёный маркер — доступен, красный — недоступен. Все точки появляются в избранном. |
| **История и графики** | Хранить измерения пинга, падения и восстановления в SQLite. Просматривать графики и экспортировать историю в CSV. |
| **Трафик в реальном времени** | Видеть приём и отправку всего компьютера, график последних 60 секунд и накопленный учёт трафика. |
| **Telegram-уведомления** | Подключить своего бота и включить уведомления для нужных хостов. Неотправленные сообщения остаются в очереди повторной доставки. |
| **Трей и виджет** | Продолжать мониторинг в фоне. Настроить перемещаемый виджет хостов или трафика, графики и режим поверх окон. |
| **Сетевые инструменты** | Разовый пинг, трассировка, DNS-запросы и сравнение DNS, WHOIS, сканеры TCP-портов и LAN, HTTPS-проверки, внешний IP и сетевые интерфейсы. |
| **Диагностика** | Сохранять профили, запускать сеансы качества связи, оценивать потери и jitter, сравнивать отчёты и выгружать ZIP для поддержки. |
| **Настройка интерфейса** | Английский, русский и казахский; тёмная, светлая или системная тема; тихий режим и таймер остановки мониторинга. |

**Интервалы опроса:** 1, 5, 15, 30 минут; 1 или 3 часа. Размер данных ICMP: **1–65 000 байт**. Таймаут: **250–10 000 мс**.

## Запуск в Windows

1. Скачайте архив Windows-сборки `SuperPingerDesktop-v0.3-Windows-x64.zip`, если он приложен к релизу.
2. Распакуйте **весь архив** в отдельную папку.
3. Запустите `SuperPingerDesktop.exe`. Папка `_internal` должна оставаться рядом с EXE.

Устанавливать Python для готовой сборки не нужно. Исходники включены в папку `source/`. Текущая сборка не подписана цифровым сертификатом.

Для обновления завершите старую версию через меню трея и распакуйте новую в отдельную папку. Хосты, история и настройки сохраняются в той же локальной базе.

## Первый хост

1. Откройте **«Карта хостов»** и щёлкните нужное место либо добавьте хост по координатам.
2. Введите имя и IP-адрес или DNS-имя.
3. Задайте интервал опроса, размер пакета, таймаут и порог неудач.
4. Сохраните: хост появится на карте и в **«Избранном»**.
5. Двойной щелчок открывает график и события. Кнопка **«Пинг сейчас»** запускает ручную проверку.

Координаты выбираете вы: IP не определяет положение маркера. По умолчанию хост получает статус «Недоступен» после двух неудачных проверок подряд. Ручной пинг также влияет на статус.

## Язык интерфейса

Откройте **Settings → Interface language** и выберите **English / Русский / Қазақша**. По умолчанию установлен английский. Выбор сохраняется сразу и применяется после полного перезапуска: **меню трея → Exit / Выход**, затем снова запустите приложение. Сворачивание в трей не считается перезапуском.

Имена пользовательских хостов и ранее сохранённые результаты остаются в исходном виде. Вывод системных команд, окна Windows и подписи карты могут использовать свой язык.

## Подключение Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. Отправьте ему `/start` или добавьте его в группу с правом отправки сообщений.
3. В **«Настройках»** укажите токен и chat ID, включите отправку уведомлений и сохраните.
4. Нажмите **«Отправить тест»**, чтобы проверить подключение.
5. Включите уведомления Telegram в настройках каждого нужного хоста.

Токен защищается Windows DPAPI для текущего пользователя Windows. При ошибке доставки выполняется до пяти попыток; кнопка **«Повторить очередь»** позволяет запустить их снова. Бот отправляет уведомления; управление компьютером командами Telegram не предусмотрено.

## Данные и особенности работы

- База: `%LOCALAPPDATA%\SuperPingerDesktop\monitor.sqlite3`.
- Согласованную копию SQLite можно создать через **«Настройки → Резервная копия базы»**.
- Программа должна быть запущена. Во сне и после выключения ПК проверки не выполняются. Версия 0.3 не является службой Windows и не имеет встроенного автозапуска.
- Потеря пакетов может означать фильтрацию ICMP или таймаут, а не выключение устройства.
- Трафик суммируется по интерфейсам, пока программа работает. VPN может приводить к двойному учёту. Это не трафик отдельного хоста и не расчёт оператора.
- Для новых участков карты нужен интернет. Недоступность карты не останавливает пинг.

## Запуск из исходников

Нужны **Windows и Python 3.12 x64**. Откройте PowerShell в корне репозитория:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Сборка Windows-версии:

```powershell
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm SuperPingerDesktop.spec
```

Результат: `dist/SuperPingerDesktop/`. Скрипт `build.ps1` также умеет создавать окружение и собирать приложение.

Тесты:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -p "test_*.py" -v
```

Для версии 0.3 прошли 33 автоматических теста и проверка запуска EXE на трёх языках. Реальную доставку Telegram и сохранение токена DPAPI ещё нужно проверить под обычной учётной записью Windows с настоящим ботом: изолированная среда сборки не позволила проверить этот сценарий.
