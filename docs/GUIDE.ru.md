# SuperPinger Desktop 0.3

Мониторинг и дополнительные сетевые инструменты для Windows 10/11 x64, Python + Qt (PySide6).

## Язык интерфейса — новое в 0.3

По умолчанию используется **English**, в том числе при обновлении с 0.2 без сохранённой языковой настройки. В **Settings → Interface language** доступны **English / Русский / Қазақша**. Выбор сохраняется сразу в базе данных. Чтобы применить его, полностью завершите приложение через **меню трея → Exit / Выход / Шығу** и запустите снова. Простое закрытие окна в трей не перезапускает приложение.

Переведены страницы мониторинга, инструменты, диагностика, диалоги приложения, трей, виджет и новые сообщения. Имена ваших хостов и профилей, сохранённые результаты и уже поставленные в очередь Telegram-сообщения остаются в исходном виде. Ответы сетевых служб, вывод системных команд, подписи карты и системные окна Windows могут использовать свой язык.

Исходники этой версии находятся в папке **source/** внутри архива с программой. Запуск из исходников: установите зависимости из `requirements.txt`, затем выполните `python app.py`. Словари переводов: `translations.py`, загрузка выбранного языка: `i18n.py`.

## Что нового в 0.2

Основной мониторинг сохранён. Добавлены разделы **«Инструменты»** и **«Диагностика»** по функционалу мобильного SuperPinger 1.8. Подробности и границы переноса: [CHANGELOG.md](../CHANGELOG.md).

Для обновления завершите старую программу через меню трея → «Выход» и распакуйте новую сборку в отдельную папку. Новая версия использует ту же базу в `%LOCALAPPDATA%\SuperPingerDesktop`: точки, история и Telegram-настройки сохраняются. Перед обновлением можно сделать резервную копию из настроек. Схема расширяется новыми таблицами, существующие записи не удаляются.

## Запуск готовой версии

Распакуйте **весь** архив `SuperPingerDesktop-v0.3-Windows-x64.zip` и запустите `SuperPingerDesktop.exe` внутри папки. Python устанавливать не нужно. Папка `_internal` должна оставаться рядом с EXE. Приложение не требует прав администратора. Сборка не подписана цифровым сертификатом.

## Хосты и карта

1. Откройте «Карта хостов» и щёлкните нужное место. Перетаскивание двигает карту, колесо меняет масштаб.
2. Укажите имя, IPv4/IPv6 или DNS-имя. Координаты выбираются пользователем: IP не геолокируется.
3. Настройте размер данных ICMP (1–65000 байт), таймаут (250–10000 мс), интервал **1, 5, 15, 30 минут, 1 или 3 часа**.
4. Точка автоматически попадёт в «Избранное». Там доступны ручной пинг, настройки и история. Двойной щелчок открывает график и журнал.
5. Для переноса точки: откройте её → «Переместить точку» → щёлкните новое место.

Зелёный маркер — доступен, красный — недоступен после заданного числа неудач, серый — статус ещё неизвестен, золотистый — автоматический мониторинг выключен. По умолчанию падение фиксируется после **двух** последовательных неудач; настройка доступна для каждого хоста. Первое успешное измерение записывается как начальное состояние, но не вызывает Telegram-оповещение о восстановлении. Ручные проверки также влияют на статус и перезапускают отсчёт интервала.

Один опрос — один ICMP Echo. Фильтрация ICMP или таймаут считаются отсутствием ответа; это не всегда означает, что устройство выключено. Ошибка разрешения DNS также считается неудачной проверкой. Мониторинг активируется при запуске приложения, расписание отсчитывается от завершения предыдущей проверки. После перезапуска хосты проверяются заново. Одновременно выполняется до 8 проверок, очередь ограничена 32 заданиями; большой список обслуживается постепенно.

## История и данные

SQLite: `%LOCALAPPDATA%\SuperPingerDesktop\monitor.sqlite3`.

Хранятся точки, настройки, каждое измерение, смены состояния и очередь Telegram. Графики строятся по сохранённым измерениям; отдельно сохранять картинки не нужно. История не удаляется автоматически. На экране до 2000 последних записей выбранного периода; CSV выгружает все измерения периода. Процент доступности — доля успешных проверок, а не точное время доступности. Простой отсчитывается от подтверждённого падения до успешной проверки. Если программа была закрыта или компьютер спал, реальное время смены состояния в этом промежутке неизвестно.

«Настройки → Резервная копия базы» создаёт согласованную копию SQLite даже при работающем мониторинге. Для восстановления завершите приложение через трей и замените базу копией. Защищённый токен Telegram переносим только в пределах той же учётной записи Windows; на другом компьютере его нужно ввести заново. При смене адреса существующего хоста старые измерения остаются в его истории; для независимой истории создайте новый хост.

## Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. Отправьте боту `/start`; для группового чата добавьте бота в группу и разрешите отправку сообщений.
3. Введите токен и chat ID в «Настройки». ID группы обычно отрицательный. Для публичного канала можно использовать `@channelname`; боту нужны права отправки.
4. Сохраните настройки, нажмите «Отправить тест» и проверьте статус внизу окна.
5. Включите глобальную отправку и флажок Telegram в настройках нужных хостов.

Оповещения содержат имя, адрес, время и длительность простоя при восстановлении. Токен защищён DPAPI текущего пользователя Windows; открытый токен не записывается в базу. Пустое поле токена при сохранении оставляет прежний токен. Неотправленные сообщения остаются в очереди: до 5 попыток с паузой 60 секунд, затем ручная кнопка «Повторить очередь». Отключение глобальной отправки приостанавливает уже накопленную очередь, но не удаляет её; новые уведомления при выключенной отправке не создаются. Если сеть восстановилась позже, придут сохранённые события с исходным временем.

Бот используется для исходящих уведомлений. Управление компьютером командами из Telegram в эту версию не входит.

## Трей и виджет

Крестик окна по умолчанию скрывает приложение в трей; опрос и Telegram продолжаются. Для остановки: правый щелчок по значку → «Выход». Во время сна или выключения ПК мониторинг не работает; приложение не является системной службой и пока не имеет автозапуска Windows.

«Виджет → ⚙» позволяет выбрать режим хостов или трафика, нужные хосты, включить/выключить графики и режим поверх окон. Виджет — компактное перемещаемое окно, а не закреплённый компонент оболочки Windows. Двойной щелчок по хосту запускает пинг. Настройки, размер и положение сохраняются.

На главной показана суммарная скорость приёма/отправки всех интерфейсов, включая LAN; при VPN возможен двойной учёт. Этот график отражает последние 60 секунд работы, а не загрузку отдельного хоста.

## Карта и сторонние компоненты

Карта — © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright). Ключ API не нужен. Загружаются только видимые участки, локальный кэш сохраняется минимум 7 дней. Новые участки требуют интернета; доступность публичного сервера не гарантирована. При отсутствии карты мониторинг продолжает работать и координаты можно вводить вручную. [Правила сервиса тайлов](https://operations.osmfoundation.org/policies/tiles/).

Используются PySide6 / Qt (LGPLv3), psutil (BSD) и PyInstaller (GPL с исключением для сборок). Упакованные библиотеки динамические и расположены в `_internal`; исходники приложения приложены отдельно. См. THIRD_PARTY.md и папку лицензий в сборке.

## Исходники и сборка

Установите Python 3.12 x64, откройте PowerShell в этой папке и выполните `./build.ps1`.

Для запуска из исходников: установите `requirements.txt`, затем `python app.py`.
Проверки: `python -m unittest discover -p "test_*.py" -v`.

## Проверено при подготовке

Проверены SQLite, пороги падений, восстановление, сохранение истории после повторного открытия БД, удаление хоста с ожидающим результатом, валидация, очередь сообщений, реальные ICMP IPv4/IPv6 localhost, страницы Qt, диалог точки, карта, графики и виджет. Тестовые данные изолированы от пользовательской базы.

Реальная доставка Telegram не проверена: токен и chat ID не предоставлены. DPAPI в изолированной учётной записи среды сборки возвращает ошибку профиля; проверку сохранения токена нужно выполнить при обычном запуске под своей учётной записью Windows. Приложение показывает ошибку и не сохраняет токен открытым текстом.
